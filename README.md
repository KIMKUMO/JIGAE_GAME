# 지게 라디오

지게에 라디오를 지고 소리봉 정상까지 올라가는 1인칭 3D 웹 게임 프로토타입입니다.

**플레이:** https://kimkumo.github.io/JIGAE_GAME/

산에는 길이 없고 어느 쪽으로 올라가도 정상에 닿습니다. 대신 산이 여러 구간으로 나뉘어 있어서 어떤 경로로 오르든 서로 다른 구간을 두세 개 지나게 됩니다.

| 구간 | 특징 |
| --- | --- |
| 억새 능선 | 완만하고 매끈한 풀밭, 억새가 핀다 |
| 울퉁불퉁 너덜지대 | 바닥이 울퉁불퉁하고 돌과 바위가 많아 라디오가 계속 덜컹거린다 |
| 가파른 비탈 | 아래위는 평평하고 가운데가 벽처럼 가파르다 |
| 구불구불 돌계단 | 구불구불 이어진 돌계단, 계단을 밟을 때마다 라디오가 들썩인다 |
| 단풍 숲 | 단풍나무가 빽빽해 사이로 길을 골라 가야 한다 |

산기슭에는 구간 이름을 적은 표지판이 있고, 화면 왼쪽 위에 지금 있는 구간이 나옵니다.

화면은 지게꾼의 1인칭 시점입니다. 아래를 보면 자기 팔과 다리, 작대기가 보입니다. 떨어진 라디오는 탱탱볼처럼 1~3번(매번 무작위) 튀고 그다음 땅에 닿으면 그 자리에서 멈춥니다. 높은 곳에서 떨어질수록 멀리 날아갑니다. 가서 주워 다시 지고 정상 돌탑까지 가면 됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| 마우스 | 둘러보기 (화면 클릭으로 마우스 고정, `Esc`로 풀기). 천천히 둘러보는 건 괜찮지만 좌우로 세게 흔들면 라디오가 떨어짐 |
| `W` `S` | 보는 방향으로 앞뒤 걷기 |
| `A` `D` | 옆걸음 |
| `Shift` | 달리기 (빠르지만 라디오가 크게 출렁임) |
| `Space` | 몸 숙이기: 뒤로 쏠린 라디오 잡기 (대신 느려짐) |
| `Q` `E` | 좌우로 버티기 |
| `F` | 떨어진 라디오 줍기 (가까이 있을 때 `Space`도 됨) |
| `M` | 소리 끄기/켜기 |

터치 기기에서는 화면에 버튼이 나타납니다.

## 파일

- `index.html`: 화면 구성과 HUD
- `style.css`: 스타일
- `game.js`: 지형 생성, 1인칭 캐릭터, 라디오 균형과 튕김 물리, 소리

빌드 과정은 없습니다. [three.js r128](https://threejs.org/)을 CDN에서 불러옵니다. 로컬에서 실행하려면 이 폴더에서 정적 서버를 띄우면 됩니다.

```
python -m http.server 8000
```
