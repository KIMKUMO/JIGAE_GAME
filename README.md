# 지게 라디오

지게에 라디오를 지고 소리봉(해발 1,350m) 정상까지 올라가는 1인칭 3D 웹 게임 프로토타입입니다.

**플레이:** https://kimkumo.github.io/JIGAE_GAME/

## 지도

- 지도는 가로 약 1.1km, 세로 약 1.3km입니다. 아래쪽 산기슭 평지 네 곳 중 한 곳(매번 무작위)에서 출발하고, 정상은 지도 맨 위 가운데에 있습니다. 출발점에서 정상까지 직선으로 약 1.1~1.2km, 실제로 걸으면 1.2~1.4km입니다.
- 길은 없지만 지형이 방향을 갈라 놓습니다.
  - **계곡**: 산 중턱을 가로지르는 깊이 약 28m의 협곡입니다. 벽은 오를 수 없고 다리 4개(**흔들다리** 2개, **외나무다리**, **돌다리**) 또는 **여울**(물을 건너는 완만한 곳)로만 건널 수 있습니다.
  - **폭포**: 계곡 북쪽 벽으로 개울이 떨어집니다. 근처에서는 물보라에 라디오가 흔들립니다.
  - **절벽 띠**: 높은 곳을 가로지르는 16m 절벽입니다. 두 군데 **틈**으로만 오를 수 있습니다. 절벽이나 계곡 벽에서 발을 헛디디면 미끄러져 떨어지고 라디오도 떨어집니다.
- 산은 높이 10~17m의 나무가 빽빽한 숲으로 덮여 있습니다(약 2만 그루). 줄기 사이는 지나갈 수 있지만 좁습니다.
- 산은 출발 평지를 지나자마자 가팔라지고, 가파른 띠와 좁은 턱이 번갈아 나옵니다(평균 경사 약 50%).
- 특수 구간은 올 때마다 다른 곳에 생깁니다(10종류, 반지름 30~100m 구간 80~90곳). 산의 약 3분의 2가 특수 구간이고 평범한 비탈은 그 사이에 조금씩 남아 있습니다. 주소 뒤에 `?seed=숫자`를 붙이면 같은 지도를 다시 할 수 있습니다.

| 구간 | 플레이 방식 |
| --- | --- |
| 구불구불 돌계단 | 바위투성이 험한 비탈 사이로 돌계단이 구불구불 나 있습니다. 계단은 안전하지만 한 칸마다 라디오가 들썩이고, 계단 밖 비탈은 느리고 미끄러져 내려가며 계속 덜컹거립니다 |
| 너덜지대 | 돌이 흘러내려 멈춰 있으면 아래로 미끄러집니다(걷는 중에는 조금씩만 밀림). 바닥이 울퉁불퉁해 계속 덜컹거립니다 |
| 가파른 비탈 | 걷는 속도가 줄고, 앞으로 걷지 않으면 뒤로 밀려 내려갑니다. 숙이기(`Space`)가 필수입니다 |
| 이끼 낀 바위 | 미끄러워서 속도가 잘 붙지 않고, 한번 움직이면 잘 멈추지도 돌지도 못합니다. 가끔 발이 옆으로 미끄러집니다 |
| 바람 부는 억새 능선 | 몇 초마다 돌풍이 불어 라디오가 한쪽으로 쏠립니다. 화면 아래 안내대로 `Q`/`E`로 버팁니다 |
| 안개 낀 단풍 숲 | 짙은 안개로 앞이 거의 안 보이고 정상 방향 화살표가 꺼집니다. 단풍나무가 빽빽합니다 |
| 진흙탕 | 발이 푹푹 빠져 아주 느리고(최대 1.6m/s) 뛸 수 없습니다. 걸음마다 라디오가 들썩입니다 |
| 낙석 지대 | 몇 초마다 위에서 바위가 굴러옵니다. 옆으로 비켜서 피해야 하고, 맞으면 라디오를 놓칩니다 |
| 쓰러진 나무 | 경사를 가로질러 통나무가 줄지어 쓰러져 있습니다. 넘을 때마다 느려지고 라디오가 덜컹거립니다 |
| 낙엽 구덩이 | 낙엽 밑에 구덩이가 숨어 있습니다. 짙은 자국을 밟으면 발이 빠져 멈추고 라디오가 휘청합니다 |
| 흔들다리 | 양 끝은 묶여 있고 가운데가 좌우로 최대 1.5m쯤 출렁입니다. 다리 바닥이 실제로 움직여 몸도 함께 밀리고, 화면도 기울어집니다. 천천히 `Q`/`E`로 버티며 건너야 하고, 뛰면 거의 떨어집니다 |
| 외나무다리 | 통나무 한 그루가 걸쳐 있습니다. 난간이 없고 몸이 옆으로 밀려서 `A`/`D`로 조금씩 가운데를 지켜야 합니다. 벗어나면 계곡으로 떨어지고 라디오도 놓칩니다 |
| 돌다리 | 흔들림 없는 튼튼한 다리입니다. 대신 위치에 따라 돌아가야 할 수 있습니다 |
| 여울·개울 | 물속에서는 느려지고 미끄러우며 물살에 라디오가 흔들립니다 |

화면은 지게꾼의 1인칭 시점입니다. 아래를 보면 자기 팔과 다리, 작대기가 보입니다. 떨어진 라디오는 탱탱볼처럼 1~3번(매번 무작위) 튀고 그다음 땅에 닿으면 그 자리에서 멈춥니다. 높은 곳에서 떨어질수록 멀리 날아가고, 나무 줄기나 바위에 부딪히면 튕겨 나옵니다. 협곡 바닥으로 떨어지면 가장 가까운 다리 초입(내가 있는 쪽)으로 돌아옵니다. 가서 주워 다시 지고 정상 돌탑까지 가면 됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| 마우스 | 둘러보기 (화면 클릭으로 마우스 고정, `Esc`로 풀기). 시야를 돌리면 라디오가 바깥으로 쏠리고, 좌우로 빠르게 흔들면 1~2초 만에 떨어짐 |
| `W` `S` | 보는 방향으로 앞뒤 걷기 |
| `A` `D` | 옆걸음 |
| `Shift` | 달리기 (빠르지만 라디오가 크게 출렁임) |
| `Space` | 몸 숙이기: 뒤로 쏠린 라디오 잡기 (대신 느려짐) |
| `Q` `E` | 좌우로 버티기 |
| `F` | 떨어진 라디오 줍기 (가까이 있을 때 `Space`도 됨) |
| `M` | 소리 끄기/켜기 |

터치 기기에서는 화면에 버튼이 나타납니다.

## 파일

- `index.html`: 화면 구성과 HUD
- `style.css`: 스타일
- `game.js`: 지형 생성, 1인칭 캐릭터, 라디오 균형과 튕김 물리, 소리

빌드 과정은 없습니다. [three.js r128](https://threejs.org/)을 CDN에서 불러옵니다. 로컬에서 실행하려면 이 폴더에서 정적 서버를 띄우면 됩니다.

```
python -m http.server 8000
```
