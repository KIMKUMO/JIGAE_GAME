# 지게 라디오

지게에 라디오를 지고 소리봉 정상까지 올라가는 1인칭 3D 웹 게임 프로토타입입니다.

**플레이:** https://kimkumo.github.io/JIGAE_GAME/

산에는 길이 없습니다. 지름 약 800m, 높이 150m의 산을 어느 방향으로, 어떤 경로로 올라가도 정상에 닿을 수 있습니다. 곧장 오르면 짧지만 가팔라서 라디오가 뒤로 쏠리고, 비스듬히 지그재그로 오르면 길지만 편합니다. 나무와 큰 바위는 피해서 돌아가야 하지만 그 사이는 항상 지나갈 수 있습니다. 화면 왼쪽 위 화살표는 정상 방향을 가리킵니다.

화면은 지게꾼의 1인칭 시점입니다. 아래를 보면 자기 팔과 다리, 작대기가 보입니다. 떨어진 라디오는 탱탱볼처럼 최대 3번 튀고, 4번째로 땅에 닿으면 그 자리에서 멈춥니다. 가서 주워 다시 지고 정상 돌탑까지 가면 됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| 마우스 | 둘러보기 (화면 클릭으로 마우스 고정, `Esc`로 풀기). 둘러보기만으로는 라디오가 떨어지지 않음 |
| `W` `S` | 보는 방향으로 앞뒤 걷기 |
| `A` `D` | 옆걸음 |
| `Shift` | 달리기 (빠르지만 라디오가 크게 출렁임) |
| `Space` | 몸 숙이기: 뒤로 쏠린 라디오 잡기 (대신 느려짐) |
| `Q` `E` | 좌우로 버티기 |
| `F` | 떨어진 라디오 줍기 (가까이 있을 때 `Space`도 됨) |
| `M` | 소리 끄기/켜기 |

터치 기기에서는 화면에 버튼이 나타납니다.

## 파일

- `index.html`: 화면 구성과 HUD
- `style.css`: 스타일
- `game.js`: 지형 생성, 1인칭 캐릭터, 라디오 균형과 튕김 물리, 소리

빌드 과정은 없습니다. [three.js r128](https://threejs.org/)을 CDN에서 불러옵니다. 로컬에서 실행하려면 이 폴더에서 정적 서버를 띄우면 됩니다.

```
python -m http.server 8000
```
