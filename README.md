# 지게 라디오

지게에 라디오를 지고 소리봉 정상까지 올라가는 3D 웹 게임 프로토타입입니다.

**플레이:** https://kimkumo.github.io/JIGAE_GAME/

정해진 길은 없습니다. 산은 지름 약 800m로, 둘레를 따라 절벽 띠가 네 겹 둘러져 있어서 정상만 보고 직진하면 막힙니다. 절벽이 끊긴 곳과 숲 사이로 길처럼 보이는 곳을 직접 찾아 올라가야 합니다. 나무에 묶인 산악회 리본, 돌무더기, 풀이 닳은 자국이 옛 등산로의 흔적이고, 그 흔적을 따라가면 정상까지 이어집니다. 화면 왼쪽 위 화살표는 정상 방향을 가리킵니다.

가파른 곳에서는 라디오가 뒤로 쏠리고, 너무 기울면 떨어집니다. 경사가 45°를 넘는 곳은 똑바로 오를 수 없으니 비스듬히 올라가거나 다른 길을 찾으세요. 나무와 큰 바위는 지나갈 수 없습니다. 떨어진 라디오는 탱탱볼처럼 최대 3번 튀고, 4번째로 땅에 닿으면 그 자리에서 멈춥니다. 가서 주워 다시 지고 정상 돌탑까지 가면 됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `W` `S` | 걷기 |
| `A` `D` | 방향 바꾸기 |
| `Shift` | 달리기 (빠르지만 라디오가 크게 출렁임) |
| `Space` | 몸 숙이기: 뒤로 쏠린 라디오 잡기 (대신 느려짐) |
| `Q` `E` | 좌우로 버티기 |
| `F` | 떨어진 라디오 줍기 (가까이 있을 때 `Space`도 됨) |
| `M` | 소리 끄기/켜기 |
| 마우스 드래그 / 휠 | 시점 회전 / 확대 |

터치 기기에서는 화면에 버튼이 나타납니다.

## 파일

- `index.html`: 화면 구성과 HUD
- `style.css`: 스타일
- `game.js`: 지형(능선, 절벽 띠, 옛 등산로 흔적) 생성, 캐릭터, 라디오 균형과 튕김 물리, 소리

빌드 과정은 없습니다. [three.js r128](https://threejs.org/)을 CDN에서 불러옵니다. 로컬에서 실행하려면 이 폴더에서 정적 서버를 띄우면 됩니다.

```
python -m http.server 8000
```
